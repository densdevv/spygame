Comment jouer

Casus Kim? est un jeu de déduction sociale pour les groupes d'amis, axé sur la rapidité, l'esprit et le bluff. L'objectif principal est d'identifier les espions cachés ou, si vous êtes l'espion, de deviner le lieu/la personne secret(e) à partir d'indices subtils.

Règles de base

  1. Distribution des rôles : Les joueurs prennent l'appareil à tour de rôle et consultent leur rôle. Les Civils voient un lieu (ex. : Paris) ou une personne (ex. : Elon Musk) selon la catégorie choisie. L'Espion ne voit pas cette information et sait seulement qu'il est l'espion.
  2. Questions : Un joueur commence en posant une question à un autre joueur. Les questions doivent être ouvertes autant que possible (ex. : "Quel temps fait-il là-bas aujourd'hui ?" ou "Cette personne est-elle en vie ?").
  3. Flux d'information : Les civils doivent éviter de donner trop de détails tout en convainquant les autres qu'ils connaissent le lieu/la personne. L'espion essaiera de reconstituer les indices à partir des réponses.
  4. Objectif de l'espion : L'espion écoute les échanges pour comprendre quel lieu ou quelle personne est évoquée.

Fin de la manche

  • Quand le temps est écoulé : Si le minuteur se termine, les joueurs votent pour désigner l'espion. Si le joueur le plus voté n'est pas l'espion, les espions gagnent.
  • Si une supposition est faite : L'espion peut à tout moment annoncer une supposition (lieu ou personne). Une supposition correcte donne la victoire à l'espion ; une supposition incorrecte donne la victoire aux civils.
  • Si l'espion est découvert : Si le groupe identifie l'espion, les civils gagnent.

Conseil : Si vous êtes civil, posez des questions suffisamment spécifiques pour les civils mais assez vagues pour tromper l'espion. Si vous êtes l'espion, assemblez les indices comme des pièces de puzzle.
